# RoleSpec OS v2.0.0

RoleSpec OS v2.0.0 establishes a fresh baseline release for the private,
local-first job-search workspace.

It integrates manual job-search tools, tailored resume management, and optional
agent-assisted application preparation into a single-owner desktop and web
application. Core manual editing, intake, and application tracking remain
available without an AI provider.

## Highlights

- **Today leads the dashboard.** Applications today, follow-ups due, and the next
  seven days sit at the top of Home. Each metric uses a colour-coded state
  badge instead of plain text.
- **Configurable daily application goal.** Choose a daily application target
  from 1 to 20 in **Settings → Preferences**; the dashboard and board use the
  same stored target.
- **Ranking explains itself.** Every saved role displays its score, evidence
  coverage, and a "Why this rank?" progressive disclosure with colour-coded factor
  badges, replacing walls of text with scannable factor breakdowns.
- **Phone-first pipeline board.** The application board adapts to one status column
  at a time on mobile viewports, navigation requires no horizontal scrolling, and
  the desktop sidebar collapses from the mark beside the logo.
- **Progressive disclosure.** Preparation runs, ranked roles, and attention rows
  keep immediate actions visible while placing secondary details behind explicit
  expansion.
- **Resume studio.** Master, role-family, and job-tailored resumes with live PDF
  preview and multiple styling templates.
- **Dashboard visual regression.** A deterministic `/visual/dashboard` fixture
  evaluates card reflow and overflow constraints at 390px and 1440px breakpoints.
- **Personal-use license.** Released under the [RoleSpec OS Personal Use License 1.0](../../LICENSE)
  for personal, non-commercial use. Commercial use, monetization, redistribution,
  and patent claims are not permitted.

## Windows installation

Download `RoleSpec_2.0.0_x64-setup.exe` and compare it with `SHA256SUMS.txt`.

- The installer configures application identity and private database storage in
  `%LOCALAPPDATA%\RoleSpecData`. Back up that directory before upgrading; do not
  remove it during an upgrade.
- The installer is not Authenticode-signed; Windows may show an unknown-publisher
  or SmartScreen warning. Tauri updater signatures, when configured, verify package
  integrity separately from Windows trust.
- Automatic updates require the release's signed `latest.json` manifest. When absent,
  install updated setup executables manually.
- The desktop runtime targets Windows 10/11 x64.

## Verification and limitations

- **Fresh release baseline.** Version 2.0.0 serves as the consolidated baseline
  release for RoleSpec OS.
- **Honest testing baseline.** Repository unit test suites, TypeScript type checking,
  linting, and desktop packaging scripts are maintained in tree. Unverified or unrun
  test counts are not claimed for this release.
- **Current limitations.** A clean Windows install and in-place upgrade cycle
  have not been verified in this environment. Live third-party ATS submission,
  physical audio/microphone hardware capture, and alternative browser engines
  remain unverified.
- **Assisted workflow safety.** Application preparation assists with company research,
  resume tailoring, and ATS answers for your inspection; it never submits applications
  silently. Final submission remains under manual user control.
