# RoleSpec OS v2.0.0

RoleSpec OS now connects manual job-search tools and optional agent-assisted
preparation in one workspace. Existing manual editing and tracking remain
available without an AI provider.

- Job-search command center with persisted ranking and company research.
- Real preparation progress with pause, resume, cancellation, retry and human review.
- Candidate evidence and source provenance with explicit approval before trust.
- Resume comparison, historical validation, generated PDF preview and rollback.
- Staged applications, manual outcome confirmation, tracking and follow-up timelines.
- Tabbed job/profile/settings pages, responsive navigation, keyboard controls and
  reduced-motion support. The optional evidence studio reflects persisted steps.

Preparation does not submit employer applications or send outreach messages.
AI features require a configured provider; local/CLI providers are not bundled.

## Windows installation

Download `RoleSpec_2.0.0_x64-setup.exe` and compare it with `SHA256SUMS.txt`.
The installer retains the existing application identity and
`%LOCALAPPDATA%\RoleSpecData` location. Back up your workspace before upgrading.
Do not remove that data directory during an upgrade.

The installer is not Authenticode-signed; Windows may show an unknown-publisher
or SmartScreen warning. Updater signatures, when present, are separate from
Windows trust. Automatic updates require the release's signed `latest.json`;
otherwise install the new setup executable manually.

## Verification and limitations

The web audit passed 5,186 frontend tests, 318 extension tests, TypeScript,
ESLint, a production build and real-browser checks. The v2.0.0 desktop runtime
was freshly built and staged. See [frontend verification](../FRONTEND_QA.md)
and [the desktop guide](../DESKTOP.md) for scope and instructions.

This is suitable for supervised local-beta use. A clean v2.0.0 native install
and upgrade, live employer ATS completion, physical microphone capture and
other browser engines remain unverified. Native PDF-viewer automation failed;
PDF export bytes and local rendering were verified. Existing export-storage
tracing warnings remain. Do not treat test counts as certification of external
integrations or all desktop environments.
