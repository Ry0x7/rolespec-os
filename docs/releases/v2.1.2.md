# RoleSpec OS v2.1.2

RoleSpec OS v2.1.2 is a patch release for the Windows desktop updater. It corrects the
update verification that reported a failed relaunch, removes the installer copy left in
the temp directory after an update, and removes the empty install directory after
uninstall. The signed update flow and the install identity are unchanged.

## Updater

- The passive installer is judged by its process lifetime, not only by the executable's
  version changing. The v2.1.0 → v2.1.1 update was rerun on Windows 11 x64: the harness
  observed `RoleSpec-2.1.1-installer.exe`, waited for it to exit, and recorded the real
  installer relaunch (`installerObserved: true`, `installerExited: true`,
  `relaunchedByInstaller: true`).
- The shell now removes previous `RoleSpec-*-updater-*` directories from the temp
  directory at startup. Each update used to strand a full setup copy there.
- The uninstaller removes the now-empty `%LOCALAPPDATA%\RoleSpec` install root after its
  normal file removal.
- The passive installer still takes roughly a minute to copy the bundled runtime before
  it starts the new build. That is expected and is no longer treated as a failed launch.

## Verification

- Windows 11 x64, on the host rather than a VM: installed v2.1.0, accepted the signed
  v2.1.1 prompt, observed the passive installer exit and relaunch v2.1.1,
  `/api/health`, `/onboarding` and `/settings/preferences` returned 200, the release
  channel selector was present, and the manual-check bridge returned `upToDate`. No
  installer process remained; the uninstaller removed the install directory; the real
  `%LOCALAPPDATA%\RoleSpecData` root was restored intact. See
  [VERIFICATION.md](../VERIFICATION.md#windows-in-app-update-v210--v211-27-november-2026).
- A locally built NSIS package with the new hooks cleaned 5 stale updater directories to
  0 and its uninstaller removed the install root.
- The desktop crate's 33 unit tests pass.

## Updating

Automatic checks remain on by default, and an installed v2.1.1 can accept the signed
update to 2.1.2. Older copies without updater metadata must install a new setup file
manually.

Download `RoleSpec_2.1.2_x64-setup.exe` and compare its SHA-256 against
`SHA256SUMS.txt`. The install identity (`RoleSpec`, `com.rolespec.desktop`) and the
`%LOCALAPPDATA%\RoleSpecData` data location are unchanged, so an upgrade preserves the
workspace. The installer remains unsigned; Windows may show SmartScreen or an
unknown-publisher warning.
