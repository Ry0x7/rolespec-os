# RoleSpec OS v2.1.0

RoleSpec OS v2.1.0 puts desktop updates under your control and makes the release build
exercise the installer before it is published. It retains every capability from
[v2.0.2](v2.0.2.md).

## Desktop updates

- **Automatic checks can be turned off** in **Settings → Preferences → Desktop updates**.
  The choice is stored beside the managed data (`config/updates.json`) and read when the
  shell starts, so it applies on the next launch. A missing or malformed preference keeps
  checks enabled: a bad file must not silently stop security updates.
- **Check for updates** runs the same signed check immediately, without waiting for the
  next launch. The card reports checking, download progress, the install/restart step and
  the up-to-date result inline.
- A startup check and a manual request share one guard, so two downloads or installers can
  never race over the same files.
- The updater still verifies the artifact against the compiled-in public key and refuses a
  version that the signed manifest does not name. When a build has no signing key, the card
  says updates are not configured instead of failing silently.

## Installer and release checks

- The Windows installer and app icons, header and sidebar images were redrawn for the
  current brand. The install identity (`RoleSpec`, `com.rolespec.desktop`) and the
  `%LOCALAPPDATA%\RoleSpecData` data location are unchanged, so upgrades preserve the
  workspace.
- Release builds now install the exact installer bytes on a runner, check `/api/health`
  and onboarding, then uninstall, before the assets are published. The smoke test uses the
  managed database, matching a normal desktop launch.
- macOS app and DMG builds are still built and smoke-tested in CI only. They are unsigned,
  not notarized and not released.

## Updating

Automatic checks remain on by default. A v2.0.1 or v2.0.2 install that received updater
metadata can accept the prompt to move to 2.1.0. Older copies without updater metadata must
install a new setup file manually.

Download `RoleSpec_2.1.0_x64-setup.exe` and compare its SHA-256 against `SHA256SUMS.txt`.

The installer remains unsigned, so Windows may show SmartScreen or an unknown-publisher
warning. See [DESKTOP.md](../DESKTOP.md#windows-trust-and-smartscreen).
