# RoleSpec OS v2.1.0

RoleSpec OS 2.1 makes the daily workflow easier to scan and usable on a phone
without sideways scrolling. It also moves the source to the RoleSpec OS Personal
Use License 1.0.

## Highlights

- **Today leads the dashboard.** Applications today, follow-ups due and the next
  seven days are the first thing on Home. Each metric has a colour-coded state
  badge instead of relying on plain text.
- **The daily application goal is configurable.** Choose any whole number from
  1 to 20 in **Settings → Preferences**; the dashboard and board use the same
  stored target.
- **Ranking explains itself.** Every saved role shows its score, evidence
  coverage and a "Why this rank?" disclosure with colour-coded factor badges,
  so a long explanation is readable instead of a wall of text.
- **The pipeline works on a phone.** The board becomes one status column at a
  time below the desktop breakpoint, navigation no longer needs horizontal
  scrolling, and the desktop sidebar collapses from the mark beside the logo.
- **Long lists use progressive disclosure.** Preparation runs, ranked roles and
  attention rows keep the next action visible and put secondary detail behind an
  explicit expansion.
- **Dashboard visual regression.** The deterministic `/visual/dashboard` fixture
  captures normal and worst-case data at 390px and 1440px, fails horizontal
  overflow, and stores checked-in baselines.

## Windows installation

Download `RoleSpec_2.1.0_x64-setup.exe` and compare it with `SHA256SUMS.txt`.

- The installer retains the existing application identity and
  `%LOCALAPPDATA%\RoleSpecData` location. Back up that directory before
  upgrading; do not remove it during an upgrade.
- The installer is not Authenticode-signed. Windows may show an unknown-publisher
  or SmartScreen warning. Updater signatures, when present, are separate from
  Windows trust.
- Automatic updates require the release's signed `latest.json`. If it is absent,
  install the new setup executable manually.
- The desktop runtime remains Windows 10/11 x64 only.

## Verification

The release is built from the same source as the web QA pass in
[FRONTEND_QA.md](../FRONTEND_QA.md). That pass ran 349 test files and 5,240
tests; TypeScript, ESLint, the production build, the showcase build and its
output verifier, and four dashboard visual-regression comparisons all passed.

A clean Windows install and in-place upgrade of this build are not performed by
the release workflow; CI builds and checksums the installer, but does not install
it. Live employer ATS completion, physical microphone capture and every browser
engine remain unverified.

The release workflow builds the installer and publishes the assets. If the
updater key is not configured, the release has no `.sig` or `latest.json` and
installed copies must update manually.
