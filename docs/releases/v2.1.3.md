# RoleSpec OS v2.1.3

RoleSpec OS v2.1.3 is a patch release for the Windows updater. It removes the setup copy used
by an update during the first launch of the new build, instead of leaving it in the temp
directory until a later start.

## Updater cleanup

- The shell cleans update installer copies from the temp directory in the background at
  startup.
- If the update's own installer is still releasing its executable, cleanup retries every
  two seconds for up to a minute. A transient lock is no longer reported as a failed
  cleanup.
- The installer process, the updated app relaunch, the install identity and the
  `%LOCALAPPDATA%\RoleSpecData` data location are unchanged.

## Verification

- A locally rebuilt shell was installed on Windows 11 x64. A fake
  `%TEMP%\RoleSpec-9.9.9-updater-RETRY01` file was held open for 10 seconds; the app removed
  the directory during the same launch after the lock was released, without logging a
  failure. Its uninstaller removed the install directory.
- The previous release's published v2.1.1 → v2.1.2 update was verified end to end on the
  same host: the passive installer exited, relaunched the app, and the updated endpoints
  and settings all passed.
- The desktop crate's 33 unit tests pass.

## Updating

Automatic checks remain on by default, and an installed v2.1.2 can accept the signed update
to 2.1.3. Older copies without updater metadata must install a new setup file manually.

Download `RoleSpec_2.1.3_x64-setup.exe` and compare its SHA-256 against `SHA256SUMS.txt`.
The install identity (`RoleSpec`, `com.rolespec.desktop`) and the
`%LOCALAPPDATA%\RoleSpecData` data location are unchanged, so an upgrade preserves the
workspace. The installer remains unsigned; Windows may show SmartScreen or an
unknown-publisher warning.
