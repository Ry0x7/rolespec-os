# RoleSpec OS v2.2.0

RoleSpec OS v2.2.0 widens who the workspace is for. It adds a page for finding clients, a
preparation mode that runs without review stops, and career paths well beyond tech. It
retains every capability from [v2.1.3](v2.1.3.md).

## Find clients

- A new **Find clients** page for virtual assistants, AI automation builders, customer
  support, lead generation, social media, writing, design, video, web development,
  bookkeeping, data entry, online tutoring and local on-site services, or any service you
  type in.
- It searches public client posts on Freelancer.com, Remotive and OnlineJobs.ph. An on-site
  search asks only Freelancer.com, whose projects can be local.
- Each lead is scored from the post alone: whether it asks for your service, how the work is
  paid, where it happens and how fresh it is. Scam signals push a lead down and say why.
  Posts that never mention the service are counted, not shown.
- **Save lead** tracks it like any other opportunity, and **Draft a proposal** opens the cover
  letter editor for it. Nothing is sent to a client for you.
- Ready-made searches open Upwork, Freelancer.com, OnlineJobs.ph, LinkedIn posts, X, Reddit
  r/forhire, Google Maps near you and local part-time listings on Indeed.

## Full AI mode

- **Full AI** joins Manual and Agent-assisted in the mode switch. The agent runs the whole
  preparation without stopping for review.
- The review step completes under a recorded policy. The tailored resume is staged only when
  it validated cleanly; otherwise the source resume is used.
- A question only you can answer is never guessed: an optional step is skipped, and a
  required one stops the run with the question as the reason.
- The run still ends with a staged package. Submitting on the employer's site stays with
  you.
- One database migration adds the mode. The desktop app applies it on launch, as with
  earlier migrations.

## Career paths

- The career catalogue grows from 25 to 48 roles in 18 fields, adding administrative and
  virtual support, AI and automation, finance and bookkeeping, education, healthcare,
  hospitality and retail, logistics and skilled trades.
- Licensed roles (accountant, teacher, registered nurse, delivery driver, electrician) ask
  for the credential before they count as a match.
- Career profile suggestions include the new roles and skills.

## Website

- The hero product preview starts tipped back and settles flat as you scroll to it; feature
  previews turn in from the side. Both stay still with reduced motion.
- Previews tip toward the pointer with a soft light, and cards, model rows and the download
  card respond on hover.
- A new section shows Find clients, an interactive Full AI mode switch and the career fields.
- `npm run showcase:test` drives the built site in Chromium at 390, 768, 1024 and 1440px, in
  light and dark, and checks the scroll effect, the reduced-motion fallback, the mode switch,
  the preview dialog and the theme toggle. Pull requests that touch the site now run it.

## Updating

Automatic checks remain on by default, and an installed v2.1.x can accept the signed update.
Download `RoleSpec_2.2.0_x64-setup.exe` and compare its SHA-256 against `SHA256SUMS.txt`. The
install identity (`RoleSpec`, `com.rolespec.desktop`) and the `%LOCALAPPDATA%\RoleSpecData`
data location are unchanged, so an upgrade preserves the workspace. The installer remains
unsigned; Windows may show SmartScreen or an unknown-publisher warning.
