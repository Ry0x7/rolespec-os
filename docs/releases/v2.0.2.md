# RoleSpec OS v2.0.2

RoleSpec OS v2.0.2 adds career intelligence and evidence-aware opportunity ranking, and
closes out the first CodeQL security review of the repository. It retains every capability
from [v2.0.1](v2.0.1.md).

## Career intelligence

- **Evidence-backed career paths** in Career Profile: a local, versioned catalogue of 25
  occupations with capability requirements, adjacent roles and growth edges. The engine
  scores each path deterministically from the evidence in your profile and explains what is
  missing; it does not invent salary potential or infer skills from job titles.
- **Approved target recommendations** grouped into adjacent and growth paths, with the
  evidence and gaps behind each suggestion visible before you act on it.
- **Capability layer for profile skills**: free-text skills map through explicit aliases to
  stable capability keys, and unknown names are ignored rather than guessed by substring.
- **Versioned local seed**: `career-path-seed-2026.11.1` is original project data, not ESCO
  or O*NET content. The evaluation and the conditions for adopting an upstream taxonomy are
  recorded in [career-path-datasets.md](../career-path-datasets.md).

## Opportunity value and ranking

- **Opportunity value** answers "is this a good deal" separately from fit: verified
  compensation, effective hourly pay, workload signals and application friction are scored
  alongside eligibility, confidence and risk. Every claim is backed by a quoted excerpt or
  marked unknown or uncertain.
- **Salary normalization** handles pay periods and currencies consistently, with explicit
  unknown states instead of assuming an hours basis or a conversion rate. Exchange-rate
  fallbacks are stored with their source and timestamp.
- **Opportunity filters** across discovery and saved jobs, including pay floor, work mode,
  eligibility, workload and posting quality, with a mobile-friendly filter panel.
- **Saved search presets** keep repeat discovery searches reproducible.
- **Feedback-aware ranking**: interested, applied, interviewed and offered verdicts adjust
  the score by an explicit, visible amount. A rejection deliberately does not lower the
  score, because an outcome is not evidence about your skills.
- **Application grounding and risk** checks keep job-description text as evidence about the
  employer, not as a claim about you.

## Security

- **26 CodeQL alerts reviewed: 22 fixed, 4 dismissed as documented false positives, 0
  open.** Fixes cover:
  - SSRF guard hardening for add-by-URL and ATS fetching: DNS pre-flight checks, fixed ATS
    host allowlists, and validation of every redirect target.
  - Path-injection hardening for resume, batch and export identifiers.
  - DOM XSS removal in job match and profile avatar previews.
  - Inert HTML parsing and single-pass entity decoding in the extension extractor, company
    research and normalize services.
  - Bounded regular expressions and a linear token-edge walk in grounding, job-risk and
    salary parsing.
  - API-token hashing upgraded to PBKDF2-SHA-256 with 210,000 iterations and `AUTH_SECRET`;
    legacy SHA-256 tokens are upgraded on first successful verification.
- **CodeQL code scanning** analyzes JavaScript/TypeScript and GitHub Actions on every push
  and pull request.
- **Protected `main`**: changes merge only through a pull request after `types`, `lint`,
  `test`, `build`, `audit`, `extension` and `CodeQL` pass, the branch is up to date with
  `main`, and the rule applies to administrators.

## Upgrade

The desktop installer applies the new Prisma migrations on first launch and preserves
`%LOCALAPPDATA%\RoleSpecData`, including your database, exports and encryption keys.

Self-hosted Docker and Node.js installations should run the migrations before starting the
new build:

```bash
npx prisma migrate deploy
```

## Windows installation

Download `RoleSpec_2.0.2_x64-setup.exe` and compare its SHA-256 against `SHA256SUMS.txt`.

- The installer targets Windows 10/11 x64 and stores private data in
  `%LOCALAPPDATA%\RoleSpecData`. Back up that directory before upgrading.
- The installer is not Authenticode-signed; Windows may show an unknown-publisher or
  SmartScreen warning. Tauri updater signatures, when configured, verify package integrity
  separately from Windows trust.
- Automatic updates require the release's signed `latest.json` manifest. Without it, install
  the new setup executable manually.
- See [Frontend QA & Verification](../FRONTEND_QA.md) and [Desktop Runtime](../DESKTOP.md)
  for runtime details and operational limits.
