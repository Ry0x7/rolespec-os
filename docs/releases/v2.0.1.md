# RoleSpec OS v2.0.1

Corrects the publisher name to **Chryypt Inc** in the Windows installer,
application version properties, uninstall entry, web metadata and public guides.
The application identifier and existing workspace data location are unchanged.

Download `RoleSpec_2.0.1_x64-setup.exe` and compare its checksum with
`SHA256SUMS.txt`. Signed updater assets are supplied when the release build has
the configured updater key.

The installer is not Authenticode-signed. Windows can still display
**Unknown publisher** in its security prompt: company metadata and updater
signatures do not establish a verified Windows publisher.

This patch retains the [v2.0.0 features](v2.0.0.md) and
[documented verification limits](../FRONTEND_QA.md). A native install/upgrade
test has not been performed for this patch.
