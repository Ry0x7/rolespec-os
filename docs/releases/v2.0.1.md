# RoleSpec OS v2.0.1

RoleSpec OS v2.0.1 is a maintenance and polish patch addressing input preservation,
strict validation across non-master resumes, planner items, and job applications,
mobile editor coordination, and desktop security updates.

This release retains all baseline capabilities from [v2.0.0](v2.0.0.md).

## What's Changed

### Non-master resume validation and input preservation
- **Prerequisite and selection validation**: Creation flows for role-family and
  job-tailored resumes now validate required source resumes, target role families,
  and job applications before dispatch.
- **Clear prerequisite guidance**: When creation prerequisites are missing (such as
  needing an initial master resume, role family, or active job application), an
  inline explanation is shown directly in the dialog footer with accessible
  `aria-describedby` references instead of generic failures.
- **Input preservation on error**: Dialog submission uses client-managed form handlers
  to prevent native browser form resets. User input like titles and notes is preserved
  if a server-side action error or network failure occurs.
- **Text wrapping and overflow protection**: Long resume titles and job descriptors
  now wrap safely within tailored resume dialogs to avoid clipped text.

### Mobile editor improvements
- **Unified drawer coordination**: Mutually exclusive local drawer state ensures
  inspect, preview, history, and comparison drawers cleanly hand off focus without
  layer stacking issues on compact screens.
- **Responsive job target card**: The resume editor's linked job header and target card
  now reflow and wrap gracefully on narrow viewports, preventing horizontal overflow.
- **Clean sheet navigation**: Drawer menus and inspection triggers adapt seamlessly to
  mobile devices without horizontal scrolling.

### Planner and job validation
- **Stricter calendar and date validation**: Todos, notes, and job applications validate
  `YYYY-MM-DD` calendar dates and ISO timestamps with user-friendly formatting errors.
- **Salary boundaries**: Application salaries enforce positive integer checks with upper
  bounds constrained to database integer limits (32-bit signed max) to prevent storage errors.
- **URL validation and limits**: Job application links enforce protocol checks (`http` or `https`)
  and maximum character lengths (2,000 characters).
- **Length limits and trimming**: Todo titles (200 characters) and notes (10,000 characters)
  are trimmed and constrained to ensure clean records and prevent overflow.

### Rust dependency patches
- **Desktop crate updates**: Upgraded Tauri desktop crate dependencies in `Cargo.lock`
  to apply upstream security patches and fixes:
  - `rustix` updated to 1.1.6
  - `rustls-webpki` updated to 0.103.17
  - `syn` aligned to 2.0.119

## Release integrity

`main` is protected: changes land through a pull request, the branch must be up to date with
`main`, and the rule applies to administrators. Future releases are cut only from commits whose
pull request passed `types`, `lint`, `test`, `build`, `audit`, `extension` and `CodeQL`; CodeQL
scans JavaScript/TypeScript and the GitHub Actions workflows on every push and pull request.

Download the installer from this release's assets and compare its SHA-256 against
`SHA256SUMS.txt` before running it.

## Windows installation

Download `RoleSpec_2.0.1_x64-setup.exe` and compare its checksum against `SHA256SUMS.txt`.

- Private database storage remains in `%LOCALAPPDATA%\RoleSpecData`. Existing data
  is preserved across upgrades.
- The installer is not Authenticode-signed; Windows may show an unknown-publisher or
  SmartScreen warning. Tauri updater signatures, when configured, verify package
  integrity separately.
- See [Frontend QA & Verification](../FRONTEND_QA.md) and [Desktop Runtime](../DESKTOP.md)
  for runtime details and operational limits.
