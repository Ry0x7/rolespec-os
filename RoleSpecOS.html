Self-host with Docker +

Start with Docker Desktop. Copy the environment template and configure a cloud AI provider.

git clone https://github.com/Ry0x7/rolespec-os.git
cd rolespec-os
cp .env.docker.example .env.docker
docker compose up -d --build

Open http://localhost:3000. Your private workspace logs you in automatically. CLI subscriptions and local models are unavailable inside Docker.

Run directly with Node.js +

Requires Node.js 22+ and PostgreSQL. Configure DATABASE_URL and AUTH_SECRET in .env.

git clone https://github.com/Ry0x7/rolespec-os.git
cd rolespec-os
npm install
cp .env.example .env
# Configure .env before continuing
npx prisma migrate dev
npx prisma db seed
npm run dev

Open http://localhost:3100 and complete first-run setup. See the full setup guide for provider configuration.

A few things to know.

Is RoleSpec an AI-free app?+

You can edit resumes and track applications without AI. AI-powered analysis, tailoring, matching, and writing require a connected provider. You choose it during setup.

Does “self-hosted” mean everything stays offline?+

Your workspace runs on your machine or server. With Ollama or LM Studio, AI processing can stay local too. Subscription CLIs, free hosted models, cloud APIs, and job-board links still use external services.

Is there a hosted demo or an account to create here?+

This is the product showcase. The screenshots are from RoleSpec, not a live workspace. Install the desktop preview or self-host the app to use your own private workspace.

Can I contribute?+

Yes. Bug fixes, workflow improvements, accessibility work, documentation, and desktop packaging contributions are welcome. Start with the contributing guide.
